How do I create a CSR? 
openssl req -new -newkey rsa:2048 -nodes \
  -keyout {{.Example}}.key -out {{.Example}}.csr \
  -subj "/CN={{.Example}}" \
  -addext "subjectAltName=DNS:{{.Example}}" \
  -addext "extendedKeyUsage=serverAuth"

Keep the .key file private. Only submit the .csr.
